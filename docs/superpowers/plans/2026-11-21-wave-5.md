# Wave 5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a generic iframe embed and seven platforms (Truth Social, Imgur, Tenor, Streamable, Strava, Flickr, Rumble) to `social-embeds`, in React and `<social-embed>`, released together as 0.7.0.

**Architecture:** The generic iframe is a separate parser entry, `parseIframe`, tried after `parseEmbed`; it rebuilds one iframe from checked attributes and renders on the existing iframe path (`IframePlan` → `IframeEmbed` / `mountIframe`). Each named platform follows wave 4: a parser module in `src/parser/platforms/`, a plan in `src/core/plans/` shared by React and the element (D82), a component in `src/components/`, a route in `<SocialEmbed>`, playground samples and README rows. Truth Social, Imgur, Strava and Flickr take the script path (`ScriptPlan` + `Driver`) or the iframe-with-height path (`MessageHeight`), decided in Task 1.

**Tech Stack:** TypeScript, React 19, Vitest + Testing Library + happy-dom, pnpm 12, Next.js 16 playground, Changesets.

**Spec:** [docs/wave-5-brief.md](../../wave-5-brief.md). Read it with [docs/project-brief.md](../../project-brief.md) and `docs/decisions.md` (D14, D28, D34, D35, D53, D57, D68, D70, D80, D81, D82, D91 are referenced throughout). The wave 4 plan (`2026-11-20-wave-4.md`) shows the per-platform pattern in more detail.

## Global Constraints

- The package makes no network calls (project brief §2). No lookups or redirects; `flic.kr` codes are decoded locally.
- Named platforms keep strict input (D14). The only new extras: Streamable's wrapper `div`, and each platform's own script tag next to its markup.
- `verifyEmbed` requires `matchUrl(embed.url).url === embed.url` (D57) for every new canonical URL.
- Options never replace verified content (D68).
- Iframes are created on the client only (D28).
- Generic iframe `src`: `https:` only; a `//host/…` src becomes `https://host/…`; `http:`, `javascript:`, `data:`, `blob:`, relative, or a URL with a user name or password makes the code not a generic embed.
- Generic iframe `allow` keeps only `autoplay`, `fullscreen`, `encrypted-media`, `picture-in-picture`, `clipboard-write`, `web-share`, each with its origin list when every origin is `*`, `'self'`, `'src'`, `'none'` or an `https:` origin (maintainer, 2026-11-21).
- Generic iframe title default: `Embedded content`. Default size: 16:9.
- New `Platform` values, exactly: `'truthsocial' | 'imgur' | 'tenor' | 'streamable' | 'strava' | 'flickr' | 'rumble'`. Display names: `Truth Social`, `Imgur`, `Tenor`, `Streamable`, `Strava`, `Flickr`, `Rumble`.
- `kind`: `post` for Truth Social, Imgur, Strava, Flickr; `video` for Tenor, Streamable, Rumble.
- Lookup error, unchanged shape: `social-embeds: a {Name} URL needs a lookup: use the embed code`.
- Generic load timeout message: `social-embeds: {title} did not load` (D91).
- Samples follow D80 (English, neutral, the platform's own account where it has one, logged-out visible).
- Decisions continue at D92 in `docs/decisions.md`. Comments follow the house style (CONTRIBUTING.md, "Comments and docblocks").
- Commit messages: Conventional Commits, no AI attribution line.
- Every task ends with `pnpm test`, `pnpm lint`, `pnpm typecheck` green; tasks that touch `src/element/` also run `pnpm build && pnpm check:element`.

## Review Focus

1. Pasted code that could run inside the host page: `srcdoc`, an `on*` attribute, `src="javascript:…"`, `src="data:…"`, a `<script>` beside the iframe. `srcdoc`, handlers and scripts never reach the DOM; a bad `src` makes `parseIframe` return `null`. Test in Task 2.
2. Generic `allow="camera; microphone; autoplay *; fullscreen https://evil.example"`: the iframe gets exactly `autoplay *; fullscreen https://evil.example`. Test in Task 2 and Task 3.
3. A host-built `ParsedIframe` handed to `GenericIframeEmbed embed` with `src: 'javascript:alert(1)'` or `allow: 'camera'`: nothing unsafe renders; `genericPlan` re-checks it, reports an error for the bad `src` and drops `camera`. Test in Task 3.
4. An iframe whose host a named platform owns but whose parser rejects it (a YouTube embed with a bad id, `www.facebook.com/plugins/unknown.php`): `parseIframe` is `null`, so `<SocialEmbed>` calls `fallback` / `onError`, never the generic path. Test in Task 2 and Task 3.
5. A Rumble page URL given to `<SocialEmbed url>`, `RumbleEmbed url` or `<social-embed url>`: nothing renders and the error names the lookup. Test in Task 4 and Task 8.

### Task 2: Generic iframe — parser

**Files:**

- Create: `src/parser/iframe.ts`.
- Modify: `src/parser/platform.ts` (`ownsFrame`), every existing parser in `src/parser/platforms/` that accepts an iframe (`ownsFrame`), `src/parser/index.ts` (export `parseIframe`, `ParsedIframe`).

**Interfaces:**

- Produces: `PlatformParser.ownsFrame?: (src: ParsedUrl) => boolean` — `true` for an iframe `src` this platform's parser handles: exactly its accepted hosts, plus a path prefix where it keys on one (`www.facebook.com` + `/plugins/`). Script-only platforms (X, Instagram, Threads, Pinterest widget) leave it out.
- Produces, in `src/parser/iframe.ts`:

```ts
export type ParsedIframe = {
  src: string; // https only, after `//` → https
  title?: string;
  allow: string; // filtered; '' when nothing is kept
  allowFullscreen: boolean;
  referrerPolicy?: Exclude<ReferrerPolicy, ''>;
  sandbox?: string; // spec keywords only
  scrolling?: 'no';
  size: { width?: number; height?: number }; // width only when numeric (px)
};
export function parseIframe(html: string): ParsedIframe | null;
export function checkIframe(embed: ParsedIframe): ParsedIframe | null; // re-validates a host-built value
```

- `parseIframe` never throws, returns `null` for non-strings, and returns `null` unless the code holds exactly one `<iframe>` (anywhere in the tree; wrapper elements, links, text, comments and `<script>` tags around it are dropped). It returns `null` when `platforms.some((p) => p.ownsFrame?.(src))`.
- Size: first source with a value: `width`/`height` attributes (`pixels()`); else `width`/`height` in `px` from the inline `style`; else one ancestor's `padding-bottom` ratio via `unwrapRatio`. A percentage or missing width leaves `size.width` undefined.
